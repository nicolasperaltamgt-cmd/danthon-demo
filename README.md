# Danthon — demo de landing mayorista

Demo de tienda online para **Danthon · Ropa urbana mayorista** (Flores, CABA).

- 67 prendas con fotos, precios mayoristas y stock por talle y color, tomados del catálogo de WhatsApp Business.
- Banner, New drop (Verano 26/27), categorías, catálogo con filtros y buscador.
- Ficha de producto con talle, color y cantidad; el pedido se envía armado por WhatsApp.

Sitio estático: abrir `index.html`.
